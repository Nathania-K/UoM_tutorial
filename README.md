**#SeqKit2026nk Project#**
[![codecov](https://codecov.io/github/Nathania-K/UoM_tutorial/branch/develop/graph/badge.svg?token=88EJKAHK5E)](https://codecov.io/github/Nathania-K/UoM_tutorial)

(Exercises for software development tutorial (Yr 1)).

This app is currently used to transcribe then translate a DNA sequence into a protein sequence. (DNA -> RNA -> Protein).

The app allows direct input (e.g. copy/paste of a sequence) into the terminal and provides either a defaulted GenBank format of DNA/RNA or a custom format of the users choosing.

Each step provides the user the opportunity to save a file with the output seen in the terminal post processing should they so wish.
